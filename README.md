# tvshow-api

REST API for collecting and exploring TV show data. It searches the TVmaze API for a show by name, saves the best match to a local SQLite database, and lets users view, update, delete, and list saved shows with pagination, sorting, and filtering. It also produces statistics on the collection by language, genre, status, or type, either as JSON data or as a chart.

*Note: This is an old project. The current code is a bit messy and everything is in a single file. I plan to review it for issues and rewrite it, including splitting it into multiple .py files, when I have time.*
